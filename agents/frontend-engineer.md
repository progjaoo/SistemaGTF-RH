# Agente: Frontend Engineer

## Missão

Implementar e revisar telas React com foco em operação, responsividade, acessibilidade e consistência visual.

## Quando Usar

- Tela nova.
- Ajuste de layout.
- Responsividade mobile.
- Componentização.
- Consumo de API no frontend.
- Exportação ou filtro visual.

## Documentos Base

- [Frontend](../docs/FRONTEND.md)
- [API](../docs/API.md)
- [Segurança](../docs/SEGURANCA.md)
- [Contribuição](../docs/CONTRIBUICAO.md)

## Responsabilidades

- Usar componentes existentes em `components/ui`.
- Manter pages em `frontend/src/pages`.
- Usar hooks em `frontend/src/hooks`.
- Colocar funções puras em `frontend/src/utils`.
- Garantir mobile via navegador.
- Preservar comportamento existente.

## Padrões

- React + TypeScript.
- styled-components.
- lucide-react para ícones.
- Vite para build.
- API via `frontend/src/api.ts`.

## Checklist

- [ ] Layout responsivo em desktop e mobile.
- [ ] Textos não vazam dos containers.
- [ ] Estados loading/erro/vazio tratados.
- [ ] Botões têm hover/focus.
- [ ] Ícones com `title`/`aria-label` quando necessário.
- [ ] `npm run build` passa.
- [ ] Nenhuma regra crítica ficou só no frontend.

## Saída Esperada

- Componentes alterados/criados.
- Comportamento preservado.
- Evidência de build.
- Observações de UX/responsividade.
